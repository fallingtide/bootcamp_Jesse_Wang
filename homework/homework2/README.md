# FE Course — Stage 02 Project Scaffold

A minimal, reproducible Python project for the feature-engineering (FE) course.
It demonstrates the tooling covered in Stage 02: an isolated environment, a
`.env`-based secret/config workflow (via `python-dotenv` and `src/config.py`),
a Jupyter notebook that verifies the setup end-to-end, and a frozen
`requirements.txt` for reproducibility. The `data/`, `notebooks/`, and `src/`
layout is meant to grow into the feature-engineering work in later stages.
